# 3%移动止损独立检验 · 2026-11-06

3%移动止损没有形成普遍改进：M3和B1在同入点、同60日比较中，四种3%规则都降低了平均单笔净收益；M1有所改善，但这些比较中的总损益仍为负。不能据此替换旧退出规则。

## 冻结口径

M1/M3/B1原选股与买入不变，每模型每天合计10000元，分别取前2/前4，100股整数单位，原费用和滑点；买入日不得卖出。三组历史原规则未变。

TC3用截至前一日的最高收盘经济价值与买入价两者较大值的97%作当日阈值，当日收盘触发时按当日收盘模拟卖出；这不是可提前确定成交价的实盘结果。PH3只用前日已知高点，两条HI3为日线两种假定路径，不能知道真实分时先后，也不构成严格收益上下界。3%为触发阈值，不是扣费后的亏损上限，跳空、T+1和不能成交均可扩大损失。

主比较仅使用60个交易日窗口已成熟且两规则均可完成退出的相同买入，逐笔核对买价及股数一致；仍开仓者在汇总和逐笔中保留，不伪造成已经完成的交易。研究还保存不设时间上限的触发路径，但不作为本次固定窗口最高收益，也不混入旧页面收益。

## 能从结果说什么

M3/B1的成对单笔中，超过一半的交易在更早退出后相对F60有所改善，但少数长趋势盈利被切断，平均结果反而下降。这说明提高“多数小交易”的表现未必提高总期望；也说明统一3%线可能过紧。这里没有继续优化阈值，不能据历史结果挑参数后宣布找到优势。

M1的改善是减少原F60亏损，仍不能证明原汉森具有可交易优势。原模型缺陷继续保留，尚有历史池不完整、历史ST未知、保守5%成交限制、公司行动和分红税假设等问题。

日线无法验证实时最高盈利后3%止损的成交顺序。未来若要认证该规则，需要合规的分钟/逐笔行情及涨跌停排队信息；当前只能提供路径诊断。
