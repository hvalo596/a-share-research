# A股全市场“便宜且生意尚可”初筛与深挖报告

研究日期：2026-11-03（上海）；行情最新完整交易日：2026-11-02。

## 结论先行

从当前可核验的5,628只人民币A股行情快照中，先筛出便宜估值线索，再用商业模式和最新披露剔除“周期高点低PE”“经营下行低PB”“好行业但价格已贵”。目前最值得进入下一轮深挖的是**招商银行**和**万华化学**两种完全不同的案例：前者是低估值的客户/资金平台，后者是有技术与一体化壁垒但强周期的化工平台。中国平安、中国太保、华域汽车、中国神华、紫金矿业属于有逻辑但必须把风险和估值拆开的观察组。国电南瑞、中国移动、长江电力、福耀、工业富联、恒瑞医药、比亚迪、北方华创是“生意可能好或未来重要，但当前不能仅凭便宜买入”的对照组。**这还不是买入清单，也没有完成每家公司的完整估值。**

## 1. 先把“便宜”讲清楚

用户原话中的“价格高于价值”若按价值投资语境应改为“价值高于价格”，即用保守估计的未来所有者收益/资产价值折现后，内在价值高于市场价格。股价低、PE低、PB低都只是线索。价值投资要回答四个直接问题：谁给公司钱；公司凭什么能持续拿到钱；竞争者为什么不能轻易把利润拿走；以今天的价格买入，未来即使出现保守情景，股东是否仍有足够回报。

本轮没有把供应商PE直接当内在价值：PE对银行、保险、资源、航运和化工的意义不同；周期高点利润会把PE压得很低，保险利润受投资与会计波动影响，银行更需要看资产质量、资本约束和可持续ROE。

## 4. 我会怎样把“5000只”变成真正的研究

第一层只做机器筛选：身份、交易状态、最新披露、PE/PB/股息、盈利是否为正、近年利润是否大幅波动。第二层按商业模式分桶：银行/保险的信用与资金成本；资源/化工/航运的周期位置与成本曲线；制造业的客户黏性、转换成本和资本回报；通信/电网/医药的研发或网络壁垒与再投资需求。第三层才估值：用保守、基准、乐观三种所有者收益或资产价值，不用单一PE。第四层做反证：如果未来三年价格、销量、利差、运价、金属价格、研发成功率或资本开支不如预期，价值还剩多少。

本轮筛选最重要的不是找出一个“冠军”，而是把低估值来源拆开：**低价来自暂时性悲观**，可能是机会；**低价来自生意恶化**，可能是价值陷阱；**低PE来自周期利润高点**，可能是最贵的时候；**好公司PE高**，可能值得研究但没有安全边际。

## 5. 现在的候选分层

**下一轮优先深挖：招商银行、万华化学。** 一个代表稳定但受金融周期影响的客户平台，一个代表技术/一体化优势但受产业周期影响的制造平台。两者能检验我们是否真正理解“好生意+低价格”而不是追逐标签。

**第二组观察：平安、太保、华域汽车、中国神华、紫金矿业。** 它们有可解释的资产或业务逻辑，但必须用资产负债表、周期价格、资本开支和分红规则估值；不能因为PE低就直接结论。

**对照组：国电南瑞、中国移动、长江电力、福耀、工业富联、恒瑞医药、比亚迪、北方华创。** 这些公司的行业位置或商业质量可能更好，但当前估值线索显示，市场已经为一部分未来支付价格；“好公司”不等于“好价格”。

**暂不优先：海螺水泥、宝钢、中远海控。** 低PB/低PE背后分别对应盈利下行、钢铁资本回报困境和航运运价周期；它们可以作为价值陷阱对照样本。
