# 跨模型退出规则比较 V1（探索性审计）

生成时间：2026-10-22（上海时间）。本报告读取 `CONFIRMATION_SUMMARY.csv`、`CONFIRMATION_YEARLY.csv` 和 `CONFIRMATION_PAIRED_BLOCKS.csv`，没有重新定义买点。

## 结论先行

这次比较没有证明某个退出规则已经成为可部署优势。相对 F60，`P15_MA20_RS` 在部分入场模型上有方向性改善，但改善不是跨模型一致；它更像是在“已经能产生趋势收益的买点”上提前识别相对弱化，而不能修复本身没有入场优势的模型。

`P15_MA20_SLOPE` 与 RS 规则的方向大体相近，但稳定性更弱。若把所有模型、前2/前4和两种涨跌停敏感性作为配置单元，任何新增规则都必须同时经受跨模型、跨年份和真正未见数据的前瞻验证。

## 数据范围与口径

- 12个入场模型 × 2种每日选择规模 × 2种涨跌停敏感性 × 4种退出规则，共 192 个聚合配置。
- 每个配置沿用相同历史入场点；退出在收盘确认后按下一可执行开盘处理，最长60个交易日。
- 金额是各日独立1万元批次的损益加总，不是一个初始1万元账户复利曲线。
- 历史 ST、公司行动和完整历史股票池存在缺口；同一历史样本已经被观察，因此不称样本外验证。
