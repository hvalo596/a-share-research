结论

固定60日退出的主要可改善对象是“先盈利、后趋势衰弱”的路径；对“短暂冲高后失败”的路径，新规则没有稳定把事后最高点变成可实现盈利。下一步应研究相对指数/行业走弱与趋势破坏的组合条件，并用后续未观察数据前瞻验证。

这不是回本概率，也不是推荐；所有金额和收益都来自已观察历史样本，完整限制见 Markdown报告。
