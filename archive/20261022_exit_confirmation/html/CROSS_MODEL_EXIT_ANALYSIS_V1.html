结论

没有规则在本轮历史样本中跨所有入场模型稳定优于F60。P15_MA20_RS在部分模型上有方向性改善，但在另一部分模型上为负；它可能帮助趋势型买点更早识别相对走弱，无法修复本身没有入场优势的模型。

历史数据已被观察，且存在股票池、历史ST、公司行动和右端截断限制，因此结果属于探索性证据，尚未替换旧模型或开启推荐。
