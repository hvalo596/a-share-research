# A股研究：把想法变成可以核对的记录

[公开网页](https://hvalo596.github.io/a-share-research/) · [超跌V2与失败检验](https://hvalo596.github.io/a-share-research/current/oversold-deepening/index.html) · [反馈](https://github.com/hvalo596/a-share-research/issues)

这是维护者与AI辅助共同完成的个人研究原型，提供模型逐笔、K线、收益图、冻结规则和失败记录。阅读网页无需GitHub登录；提交issue需要登录。

超跌V2思想：此前真实成交额相对自身历史活跃、价格有过上涨，随后加速下跌，研究是否存在卖压过头后的修复。基础65,334个历史事件经事前条件收紧到7,988个观察事件；每天最多四只、总预算1万元。**新V2仍未显示稳定正收益，确认F20日期等权均值为负。**完整方法和偏差在页面公开，不把分数当上涨概率，也不靠隐藏亏损推销。

核心12组历史模型、价值研究、右侧回踩和生肖题材分别保留，不继承超跌实验的战绩。行情、扫描与核算截止分别标记；新增独立研究有自己的冻结版本和日期。网页自身不会获取实时行情，只有本地真实采集、核算和验收后才同步。
